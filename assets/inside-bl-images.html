Scope of work

Not a stock-photo plugin — a provenance system for a mission that can't afford a rights mistake.

It starts with legally-safe sourcing — only public-domain, CC0 and CC BY imagery from Openverse and Wikimedia Commons — and wraps every image in a tamper-evident ledger: SHA-256 hashes, a source snapshot, OpenTimestamps proofs and a Wayback Machine capture, hash-chained so the record can't be quietly rewritten. Claude drafts the alt text, title, caption and credit, and every file is converted to optimized WebP on the way in.

Around that sits a full lifecycle: replace an image in place and every page follows, a where-used view before you touch anything, duplicate consolidation, e-signed model and contributor releases, and a one-screen license audit of the entire library. It installs its own updates straight from GitHub — a living system, not a finished artifact.
