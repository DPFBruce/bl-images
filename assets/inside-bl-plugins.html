The idea

Five plugins, one philosophy.

Each one replaces something DPF would otherwise rent, host elsewhere, or do by hand — and each is built the same way: the hard engineering is hidden so the day-to-day work stays simple, the admin speaks plain English, and the whole thing updates itself. Nothing here is a black box the organization can't own.

Live v1.16.86 shortcode [bl_videos]

(BL) Videos

A video library that behaves like a product. Upload goes straight to a global CDN, the words stay where search engines can read them, and the busywork is quietly automated away.

Upload

Straight to the cloud

Video goes from the browser directly to Bunny with a resumable, signed upload — big files survive a dropped connection. WordPress keeps only a lightweight link, and the secret key never leaves the server.

TUS · signed tokens · zero server strain

It writes its own first draft

The moment a video finishes, a Cloudflare Worker transcribes the audio and hands it to Claude, which drafts a house-style title, an SEO description, and the right category — waiting for a human yes.

Whisper → Claude · runs on a schedule
Design

Programmatic · container-query type
Discoverability

Imagery you can prove you're allowed to use. It finds legally-safe images, makes them fast, writes their alt text, and keeps a tamper-evident record of exactly where each one came from.

Legally safe by design

Searches Openverse and Wikimedia Commons for public-domain, CC0 and CC BY images only — or takes your own upload — so nothing with murky rights ever slips onto the site.

Provenance

Every image carries its license, a source snapshot, SHA-256 hashes, a Wayback Machine capture, and a hash-chained ledger — tamper-evident provenance, timestamped for real accountability.

Hash-chained ledger · OpenTimestamps · Wayback

Claude alt text · auto-WebP

The whole lifecycle

E-sign releases · where-used · audit

The stack it stands on

A few accounts, doing the heavy lifting.

B

Bunny Stream

Global video hosting, encoding, adaptive delivery and AI captions. The video itself never burdens the web server.

C

Cloudflare Workers + Anthropic Claude

The AI brain — transcription, slide copy, image alt text and metadata, authored on demand at the edge for pennies.

G

GitHub Releases

The update pipeline for every plugin. Each version is a public release the live site installs on its own — native “Update now.”

W

WordPress

The home base — custom post types, taxonomies, REST endpoints and a metadata model the rest of the site reads from.

O

Openverse + Wikimedia Commons

The legally-safe sources behind (BL) Images and the Slide Editor's Wikimedia search — public-domain and openly-licensed only.

Scope of work

Not five weekend plugins — a small, sustained software platform, built and refined across 2026.

Each plugin is an estimated one to several weeks of focused, senior full-stack work: cooperating PHP modules each with one job, a shared Cloudflare Worker, custom admin experiences, and an automated GitHub release pipeline — shipped as many small, deliberate versions, every one reviewed against the real site.

Together they span back-end (Bunny & Cloudflare integration, WP-Cron automation, REST wiring, tamper-evident provenance), front-end (bespoke display engines, cinematic thumbnails, an accessible bio modal, a by-eye carousel editor), design (a coherent visual language tuned at real sizes), and operations (self-updating, cost analysis, audit trails, auto cache-purge). And they keep growing — this is a living system, not a finished artifact.
